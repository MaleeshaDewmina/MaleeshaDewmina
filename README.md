# Hi, I’m Maleesha Dewmina Perera 👋

I’m a Software Engineering undergraduate from Sri Lanka studying for a BEng (Hons) in Software Engineering at London Metropolitan University. I build web and desktop applications, and I’m especially interested in how software can help people learn. My final-year project, EduMind AI, brings study planning, progress tracking and chatbot feedback into one application.

## What I work on

- **Web applications.** On [SRMSS](https://github.com/MaleeshaDewmina/SRMSS-ASE-Coursework), a team project for public transport depots, I worked on authentication, dashboards and user management.
- **Desktop software.** I built [SmartMed](https://github.com/MaleeshaDewmina/SmartMedERP-Pharmacy-Management-System) with C# and SQL Server to connect pharmacy inventory, prescription review and customer orders.
- **AI in education.** Alongside building EduMind AI, I’ve [researched how university students experience chatbot feedback](https://github.com/MaleeshaDewmina/AI-Chatbots-Student-Motivation-Research) and analysed their responses using SPSS.
